# Æther Keep releases

Signed installers, portables and Android APKs for Æther Keep, plus update metadata for the in-app updater.
This repo holds release builds only; the source is private.

- **Windows:** download the setup or portable `.exe` from Releases.
- **Android:** add this repo URL to [Obtainium](https://github.com/ImranR98/Obtainium) to install and auto-update.
